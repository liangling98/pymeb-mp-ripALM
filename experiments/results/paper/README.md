# Archived paper records

These are the original ripALM and mp-ripALM records used to prepare the paper
tables. The JSON files preserve environment metadata, arguments, options, raw
runs, and summaries; the CSV files provide convenient tabular views.

No comparison-solver implementation or result record is included. Runtime
values are specific to the paper machine; accuracy and constraint-retention
fields are the more portable checks for a rerun.

See `experiments/README.md` for the command corresponding to each file group.
